# Toolkit — калькулятор и конвертер в командной строке

Лабораторная работа №1 по Python. Пакет с двумя утилитами:
вычисление арифметических выражений и перевод единиц измерения

## Функционал

**Калькулятор** — принимает строку с выражением и возвращает результат:

```
py -m toolkit calc "2+3*4"      -> 14
py -m toolkit calc "10 / 4"     -> 2.5
py -m toolkit calc "-2 * -3"    -> 6
```

Поддержка: `+ - * /`, `//` и `%`, унарных `+` и `-` и скобок.
Приоритеты расставлены как в математике: `*` и `/` выполняются раньше `+` и `-`.

**Конвертер** — переводит значение из одной единицы в другую:

```
py -m toolkit convert 1000 --from mm --to m     -> 1.0
py -m toolkit convert 0 --from c --to f         -> 32.0
py -m toolkit convert 1.5 --from kg --to g      -> 1500.0
```

Поддерживаемые группы единиц:
- длина: `mm`, `cm`, `m`, `km`
- масса: `g`, `kg`
- температура: `c`, `f`, `k`

Регистр не важен: `KG`, `Kg` и `kg` — одно и то же(всё приводится к нижнему регистру). 
Осуществлять перевод между разными группами нельзя: `kg -> m` — ошибка. 
Для температуры идёт проверка на абсолютный ноль: `-300 c` не переведётся.

## Ошибки и коды возврата

Сообщение об ошибке уходит в `stderr`, программа завершается с кодом `2`.
Успешная команда завершается с кодом `0`.

Что считается ошибкой:
- пустое выражение
- неизвестный символ (например, буква в выражении)
- несбалансированные скобки
- деление на ноль
- неизвестная единица измерения
- попытка перевести массу в длину
- температура ниже абсолютного нуля

Проверка кода возврата в PowerShell:

```powershell
py -m toolkit calc "1/0"
echo $LASTEXITCODE    # 2
```

## Структура

```
src/toolkit/
  __main__.py        — CLI на argparse: разбирает команду и вызывает ядро
  tokenizer.py       — превращает строку в список токенов
  parser_rpn.py      — строит обратную польскую нотацию и вычисляет её
  calculator.py      — собирает всё вместе: строка -> ответ
  converter.py       — конвертер единиц
  errors.py          — классы исключений
  conversions.json   — таблица коэффициентов для длины и массы
```

**Как происходит работа калькулятора.** 
Токенизатор разбирает строку на числа, операторы и скобки, помечает унарные `+`/`-` отдельным типом.
Файл `to_rpn` переводит токены в обратную польскую нотацию(RPN) через стек: операторы ждут в стеке, пока
не придёт момент их использовать. 
Функция `evaluate` идёт по RPN и считает через стек — по принципу: один операнд для унарных, два для бинарных.

**Как происходит работа конвертера.** 
Единицы длины и массы описаны в `conversions.json` коэффициентом относительно базовой единицы группы.
Чтобы перевести из одной в другую, значение сначала переводится
в базовую, затем из базовой в целевую. 
Температура обрабатывается отдельно — через формулы перевода в Цельсий и обратно.
